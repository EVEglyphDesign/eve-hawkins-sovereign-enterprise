## The proposition in one sentence

Instead of spending the next decade renting access to your own sales pipeline, spend the
same money once, inside a twin you own, and let every other individually-owned Peterbilt
dealer contribute to it rather than buy it.

## The six moves

| # | Move | What it does |
|---|------|--------------|
| 02 | Cannibalise the CRM | Every dollar of future CRM spend is redirected into the twin |
| 03 | Backup support | The twin as the durable record behind whatever front end a dealer runs |
| 04 | Value capture | Pipeline sovereignty captured inside the twin model across the network |
| 05 | Contribution | Each dealer contributes components; components are shared |
| 06 | Transfer | The same pattern moves to electric utilities |
| 07 | The umbrella | The EVEglyph Design Global Copyright Umbrella makes contribution safe |

## What is not resolved

Section 09 of the paper prints the open register in full. The first item is the one that
matters: Tim asked twice for a guarantee that his data and the work built on it would not
be used elsewhere. He received a proposed mitigation — Luke placed in direct control —
and an offer to sign a contract. **No contract has been executed.** It should be resolved
before any extraction beyond the phone-system pilot.
